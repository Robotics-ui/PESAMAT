PesaMatrix Copy Trading Scaling Upgrade
IMPORTANT
DO NOT rewrite, remove or break the existing copy trading system.
The current production architecture is working correctly and supports approximately 2,000 slave accounts.
This task is an extension only.
Maintain backward compatibility with all existing APIs, workers, authentication, subscription enforcement, MetaApi integration, CopyFactory integration, payment logic, admin panel and user dashboard.
All current functionality must continue working without modification.
Objective
Upgrade PesaMatrix from supporting one distribution master serving approximately 2,000 slave accounts to a horizontally scalable architecture capable of supporting 10,000–15,000 slave accounts.
The system must continue using MetaApi Cloud-to-Cloud CopyFactory.
No VPS.
No MT5 terminals.
No Expert Advisors.
